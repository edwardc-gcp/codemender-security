# Top 5 GenAI & Vibe Coding Vulnerability Patterns

When fixing vulnerabilities in applications generated by LLMs or vibe-coding frameworks, use these patterns to synthesize robust guidance for `cm fix -c "<guidance>"`:

## 1. Client-Side Secret & API Key Leakage (CWE-798 / CWE-200)
* **Code Smell**: Hardcoding `GEMINI_API_KEY`, `OPENAI_API_KEY`, or `FIREBASE_ADMIN_KEY` in client components (`App.tsx`, `index.html`).
* **Exploitation**: Keys extracted from client bundle; quota drained or cloud access compromised.
* **Remediation Context**:
  `-c "Move secret usage to server-side handler; read from process.env.GEMINI_API_KEY or Google Secret Manager; do not expose key to client bundle"`

## 2. Unsanitized Prompt Concatenation / Prompt Injection (CWE-20 / OWASP LLM01)
* **Code Smell**: Direct string interpolation into LLM prompts: `const prompt = "Summarize: " + req.body.userInput;`
* **Exploitation**: Untrusted input overrides system prompt instructions.
* **Remediation Context**:
  `-c "Isolate system instructions using systemInstruction parameter; pass user text strictly as Content parts; enforce JSON structured output via responseSchema"`

## 3. Permissive Cloud & Database Security Rules (CWE-284 / CWE-732)
* **Code Smell**: Firestore `allow read, write: if true;`, open Storage buckets, or CORS `origin: "*"`.
* **Exploitation**: Unauthenticated users wipe or dump entire database.
* **Remediation Context**:
  `-c "Enforce auth check request.auth != null and restrict origin to allowed production domains"`

## 4. Dynamic Raw Query Interpolation (CWE-89 / CWE-943)
* **Code Smell**: `db.query("SELECT * FROM users WHERE email = '" + req.body.email + "'")`
* **Exploitation**: SQL / NoSQL Injection leading to auth bypass or database exfiltration.
* **Remediation Context**:
  `-c "Replace string concatenation with parameterized query placeholders or project standard ORM helper"`

## 5. Deprecated or Risky AI Dependencies (CWE-1395)
* **Code Smell**: Hallucinated package names or unmaintained wrappers.
* **Remediation Context**:
  `-c "Migrate to official Google GenAI SDK (@google/genai or google-genai in Python) and lock versions"`
